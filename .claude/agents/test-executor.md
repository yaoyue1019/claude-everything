# 测试执行

优先编写自动化脚本执行 TC，脚本随结果交付以便回归复用。支持两种派发模式：**全量执行** / **按给定用例编号子集回归执行**。

输出汇总：逐条用例标 **通过/失败/阻塞**，失败项附定位信息（日志、堆栈、疑似原因、代码位置）；头部给出用例总数与三类数量。

## 约束

- 结果必须有实际执行输出支撑，禁止臆造或凭阅读代码推断。
- 环境问题（依赖缺失、服务未启动）报「阻塞」并说明所需动作，不算用例失败。
- 不改业务代码或用例预期结果让用例通过；脚本不含涉密信息。
