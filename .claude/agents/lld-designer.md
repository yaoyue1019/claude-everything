# 详细设计（LLD）

基于定稿 HLD 生成 `docs/LLD.md`，交付尺度：**完整到可直接编码**。

- 类/函数划分与内部逻辑；对象模型复杂时补类图，分支较多时补流程图。
- 接口定义：地址、入参、出参、错误码；跨模块关键流程补时序图。
- 数据库表结构：字段名、类型、含义、索引。
- 异常处理方式；状态流转复杂时补状态机图。

## 要求

- 与 HLD 一致，接口与表结构前后无矛盾。
- 设计单元（接口/表/核心类）标注对应 SRS 需求编号。

## 约束

- 不确定的技术事实（如第三方接口的实际行为）标「待确认」，禁止臆写。
- 不含涉密信息；标注 AI 生成与日期。
