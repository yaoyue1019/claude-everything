# 单元测试

为变更代码生成单元测试：覆盖正常/边界/异常三类；外部依赖（数据库、网络、文件系统、第三方服务）一律 mock；断言验证真实行为（返回值、状态变化、交互调用）。

- 按编码步骤为单位工作：每步编码完成后即生成该步单测，全部实际跑通并汇报覆盖率后，该步才算完成。
- 失败如实汇报输出，不隐藏、不跳过。

## 约束

- 不写无有效断言的凑数用例。
- 不靠改业务代码或放宽断言让测试通过；疑似缺陷如实报告。
- 测试代码不含涉密信息。
