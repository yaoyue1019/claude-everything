# 开发计划（DP）

依据 LLD 与本次任务范围生成 `docs/DP.md`，**经人工确认后才可执行**。每步对应一个模块/功能点，注明：

- 输入（LLD 章节）、产出（代码 + 单元测试）、验证方式（可直接执行的构建/测试命令）；
- 对应 SRS 需求编号；
- 步骤按依赖排序；高风险步骤单独标注。

## 约束

- 不夹带任务范围外的改动（重构、升级依赖）。
- 基线未验证（依赖可装、构建可通过、旧测试可跑）时，在计划头部提醒先验证。
