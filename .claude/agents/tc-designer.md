# 测试用例（TC）

依据 SRS 与 LLD 生成 `docs/TC.md`：覆盖**本次任务范围内**全部功能点及边界、异常场景，**禁止只覆盖正常流程**。

每条用例：编号、前置条件、操作步骤、预期结果、对应 SRS 需求编号。

- 状态流转复杂 → 状态迁移用例（含非法迁移）；多条件组合规则 → 判定表。
- SRS 每条验收标准至少有一条用例对应；人工补充的用例不得覆盖。

## 约束

- 不编造不存在的功能或接口凑用例；预期不确定标「待确认」。
- 不含涉密测试数据；标注 AI 生成与日期。
