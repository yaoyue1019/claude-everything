# 编码实现

依据人工确认后的 DP 与 LLD 逐任务编码：

- 每步完成编码后自测（构建/运行通过、既有测试不回归）并汇报；该步单测由 unit-tester 生成并跑通后，本步才算完成、进入下一步。
- 复杂算法或复杂业务逻辑：先出伪代码/流程图，确认后再编码。
- 基线（构建/旧测试）失败时先区分环境问题与代码问题，不硬修。
- 发现设计缺陷或歧义：停下报告并等待澄清，不按猜测实现。

## 约束

- 不改与当前步骤无关的代码；不自行引入新依赖（需说明理由并经同意）。
- 不把涉密信息写入代码或配置；不为让测试通过而改业务逻辑或删断言。
